# 📈 株式売買記録アプリ

株式の売買履歴・配当金を記録し、月ごとの損益（損益通算）を自動計算するアプリです。

## できること

- **取引の記録**（買い / 売り）
  - 買い取引には「買う目的」「投資期間（短期 / 中期 / 長期）」「損切ライン」を設定可能
  - 銘柄コード（例: `7203`）を入力すると **銘柄名・市場区分・業種を自動表示**
    （東証全銘柄 約4,350件のマスタを内蔵。オフラインでも動作）
- **実現損益の自動計算**
  - 移動平均法（買付ごとに平均取得単価を更新）で売却時の損益を自動算出
- **配当金の記録**
  - **1株あたりの年間配当（直近1年の実績）を銘柄から自動取得**
  - 「自動計算」ボタンで、受取日時点の保有株数 × 1株配当（半期分）を自動入力
- **月次損益サマリー**
  - 月別の「実現損益＋配当金」を自動集計（損益通算の目安）
  - 棒グラフ・累計付きテーブル・年間サマリー
- **保有銘柄一覧**
  - 平均取得単価・評価損益・予想年間配当を表示
  - 現在値が**損切ラインに到達すると行が赤くハイライト**され「⚠ 損切ライン到達」と表示
- **データのエクスポート / インポート**（JSONファイル）

## 使い方

### 推奨: サーバー経由で起動（全機能が使えます）

Node.js 18以上をインストールした上で:

```bash
cd stock-tracker
node server.js
```

ブラウザで **http://localhost:3456** を開いてください。
現在値・1株配当は Yahoo! Finance の公開データから自動取得されます
（ブラウザから直接はCORS制限で取得できないため、ローカルサーバーが中継します）。

### 簡易: index.html を直接開く

`index.html` をダブルクリックするだけでも動きます。この場合:

- ✅ 銘柄名の自動表示、損益計算、月次サマリー、損切ライン管理 … すべて動作
- ❌ 現在値・1株配当の**自動取得のみ不可**（配当は手入力すれば損益通算に反映されます）

## データの保存場所

データはブラウザの `localStorage` に保存されます。ブラウザのデータ消去で消えるため、
定期的に「エクスポート」ボタンでJSONファイルにバックアップしてください。

## 計算方法に関する注意

- 実現損益は **移動平均法** で計算しています（税務上の総平均法とは端数が異なる場合があります）。
- 「1株配当」は Yahoo! Finance の**直近1年間の配当実績の合計**です。将来の配当予想ではありません。
- 「自動計算」は年2回配当を想定して年間配当の半分で計算します。実際の受取額（税引前/後、株数）に合わせて修正してください。
- 本アプリの数値は目安です。確定申告には証券会社の年間取引報告書をご利用ください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `app.js` | 記録・損益計算・グラフ描画ロジック |
| `style.css` | スタイル（ライト/ダークモード対応） |
| `stocks.js` | 東証上場銘柄マスタ（コード→銘柄名・市場・業種、2024-03時点） |
| `server.js` | ローカルサーバー（静的配信＋株価/配当の取得API、依存パッケージなし） |
