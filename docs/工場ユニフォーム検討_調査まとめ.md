# 工場ユニフォーム検討（新規ジャケット／ネックストラップ）調査まとめ

作成日：2026年9月6日／改訂：2026年9月7日（数値の出典を明記して全面見直し）
目的：新規ジャケット（工場訪問時の作業着）とネックストラップについて、**コスト感・発注先・納期・イメージ感**を確認する。候補は法人向けにオリジナル制作を展開している企業から各3案。

**数値の扱い**：コスト・納期・最小ロットは、掲載ページを特定できたものだけを「数値」として記載し、確度を A / B / C で明示しています。C（掲載ページを特定できないもの）は数値を採用せず「要見積」としています。

| 確度 | 意味 |
|---|---|
| **A** | 発注先サイトの該当ページに、その数値の記載がある |
| **B** | 業界メディア・各社コラムに記載された相場値（発注先自身の公表値ではない） |
| **C** | 掲載ページを特定できず＝見積でのみ確定する項目 |

**① キラメック**（kilamek-novelty.com）
- BtoB専門。専任担当と相談しながら素材・印刷・パーツを選定できる
- **完成データが手元になくてもデザイン面を相談できる**点が他社との差（後輩の指摘どおり）
- 同社は作業服・刺繍加工も扱うため、ジャケットと窓口をまとめられる可能性がある
- ただし条件がサイト上に出ていないため、比較には見積取得が必須

**② HOTSTRAP**（hotstrap.jp）
- 3案の中で唯一、**単価・納期・ロットがすべてサイト上の数値で確認できる**
- Web上の自動見積で本数・仕様別の金額とPDF見積書をその場で取得できる
- ナイロン10/15/20mm、ポリエステル、合皮、プレミアムなど選択肢が広い

**③ KANARY／青山ストラップ**（kanary.jp／ao-strap.com）
- 昇華転写のため製版不要＝版代がかからない
- グラデーション・写真・多色デザインを再現しやすい
- 本数が増えるほど単価が下がるため、まとめ発注向き

## 5. イメージ感（現行ストラップから引き継ぐ要素）

- 印刷：フルカラー昇華転写（ブルー〜パープルのグラデーション）
- 文言：「考え抜く。未来のために。／Think Deeply for the Future.」を両面に配置
- 幅：15〜20mm相当。長さ調整パーツ＋安全パーツ（着脱バックル）付き
- 金具：ナスカン（回転式）。社員証ケースとの組み合わせを想定

| 項目 | 選択肢 | 判断のポイント |
|---|---|---|
| 印刷方式 | 昇華転写（フルカラー）／シルクスクリーン（1〜6色） | 写真・グラデーションなら昇華一択。単色ロゴのみならシルクが安い |
| 素材・幅 | ナイロン／ポリエステル、10・15・20mm | 社員証用途は15〜20mmが標準。太いほど印刷が映える |
| パーツ | ナスカン、長さ調整、安全バックル、リール | 工場内での引っ掛かり対策として安全バックルは必須級 |
| ロット・単価 | 1本〜（HOTSTRAP）／30本〜（KANARY・青山） | 昇華フルカラーは232円〜。本数を増やすほど単価は下がる |
| データ | ai／eps（アウトライン化） | データがない場合はデザイン相談可の業者（キラメック等）を選ぶ |

## 6. 「一般サイトで発注したらどうなるか」の検証

### ジャケット（ユニフォームネクスト／ワークストリート／ワークキング 等）
- **メリット**：1着から購入でき社名刺繍も1着から対応／本体3,000〜4,000円台のブルゾンも選べる／納期は加工込みで約2週間、在庫があれば即日出荷も
- **デメリット**：デザインは既製品の範囲で他社と被る可能性／刺繍位置・サイズの自由度は限定的／同一品番が廃番になると翌年に揃わないリスク

### ストラップ（ラクスル／アスクルパプリ／ノベルティ系EC 等）
- **メリット**：Web完結で単価と納期が即時に分かる／小ロット・短納期に強く送料無料の設定も多い
- **デメリット**：原則、入稿データ（ai／eps）の用意が前提／細かなパーツ指定・色合わせの相談はしづらい／試作の事前確認が有料または不可の場合がある

## 7. 想定スケジュール（発注確定後）

| 方式 | 工程 | 合計 |
|---|---|---|
| ③ 既製品＋名入れ | 商品選定・現物確認 → データ入稿 → 加工・納品 | 約2週間〜1ヶ月 |
| ② 小ロットオーダー（国内） | ヒアリング・デザイン → サンプル制作・確認 → 量産・納品 | 約3〜4ヶ月 |
| ① フルオーダー | 仕様・素材決定 → 型・サンプル → 量産・納品 | 約4〜5ヶ月（海外縫製は6〜8ヶ月、染色ありで+2ヶ月） |

※ 上記は発注確定後の期間。社内での仕様決定・稟議期間が別途必要なため、着用希望日から1ヶ月以上の余裕を見込む。
